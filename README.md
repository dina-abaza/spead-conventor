# 🗣️ Text-to-Speech Web App

This is a simple **JavaScript** project that converts written text into **speech** using the Web Speech API.  
Users can type any text into an input field, then click the **"Voice"** button to hear the text spoken aloud.

---

## 🚀 Features

- 📝 Type any text in an input field
- 🔊 Click a button to hear the text spoken
- 🌐 Uses the browser's built-in **SpeechSynthesis API**
- 🎨 Simple and user-friendly interface

---

## 🛠️ Technologies Used

- **HTML** – Page structure
- **CSS** – Basic styling (optional)
- **JavaScript** – Core logic for text-to-speech

---

## 💻 How It Works

1. The user types text into an input field.
2. When the **"Voice"** button is clicked, JavaScript captures the input.
3. The script uses `SpeechSynthesisUtterance` and `speechSynthesis.speak()` to convert the text to audio.
4. The browser speaks the text using the default system voice.
